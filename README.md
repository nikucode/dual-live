# ✧ dual.live ✧

(っ˘ω˘ς )

pequeño espacio visual + musical para jugar, experimentar y crear juntos

También estamos construyendo un [estudio de ritmos offline para la terminal](experiments/terminal/README.md): sintetiza sonidos en tu equipo, permite editar instrumentos y pistas mientras suenan, y guarda sesiones como texto abierto.

---

## ✦ qué es esto?

un mini instrumento en el navegador donde puedes:

- crear visuales con código
- hacer beats tipo live coding
- mezclar imagen + sonido
- romper cosas y ver qué pasa uwu

---

## ✦ cómo usarlo

1. abre `index.html`
2. presiona **run**
3. edita el código
4. juega con sliders y sonidos ✧(≧◡≦)✧

### modo terminal

Necesitas Python 3 y `aplay`. Desde una copia del repositorio:

```bash
cd experiments/terminal
./install.sh
dual-live
```

El primer arranque enseña las teclas. Hay un [ejemplo de ritmo con acentos, repeticiones y cambio de tono](experiments/terminal/examples/primer-break.dual), además de una [guía paso a paso](experiments/terminal/README.md). Después de instalarlo, el modo terminal funciona sin internet.

La [investigación sobre patrones y eventos](docs/PATRONES-Y-EVENTOS.md) explica lo aprendido de Strudel y Ableton y los límites actuales del prototipo.
