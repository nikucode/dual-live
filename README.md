# ✧ dual.live ✧

(っ˘ω˘ς )

pequeño espacio visual + musical para jugar, experimentar y crear juntos

---

## ✦ qué es esto?

un sistema interactivo de visión computacional desarrollado en Python/OpenCV/NumPy, incorporando captura de video, detección de presencia humana, procesamiento de imágenes y máquina de estados para modificar dinámicamente parámetros visuales, es decir; 

un mini instrumento en el navegador donde puedes:

- crear visuales con código
- hacer beats tipo live coding
- mezclar imagen + sonido
- romper cosas y ver qué pasa uwu

---

## ✦ cómo usarlo

1. abre `index.html`
2. presiona **run**
3. edita el código
4. juega con sliders y sonidos ✧(≧◡≦)✧

---

## ✦ ideas para jugar

- cambia colores
- mueve imágenes con `Math.sin(time)`
- crea ritmos con `play("kick snare")`
- agrega más capas con `addLayer()`
